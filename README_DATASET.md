### About MOPED dataset download

As of the time this README document was written(**2025.06.13**), the [download link](https://homes.cs.washington.edu/~kpar/latentfusion/moped.tgz)  for MOPED is still returning a 404 error. Given the dataset license on their [website](https://latentfusion.github.io/) permits dataset holders to distribute copies, we have reuploaded [a copy of this dataset](https://huggingface.co/datasets/winka9587/MOPED/tree/main).
